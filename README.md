# Supplementary Material for *What the Survey Literature Says About Reinforcement Learning for Building Control: A Critical Synthesis*

This repository contains the supplementary evidence files accompanying the anonymous review manuscript *What the Survey Literature Says About Reinforcement Learning for Building Control: A Critical Synthesis*.

The files document the search and selection process, the verification of the included corpus, the survey-level coding for seven research questions, the RQ-specific codebooks, and the inter-rater reliability assessment.

## Contents

| File | Coverage |
| --- | --- |
| `Final_Search_PRISMA_Supplement_n22.xlsx` | Database-specific search strings, search log, route-by-route PRISMA accounting, record-level screening decisions, full-text exclusions with reasons, contextual evidence, and provenance of the 22 included reviews |
