# Supplementary Material for *What the Survey Literature Says About Reinforcement Learning for Building Control: A Critical Synthesis*

This repository contains the supplementary evidence files accompanying the anonymous review manuscript *What the Survey Literature Says About Reinforcement Learning for Building Control: A Critical Synthesis*.

The files provide survey-level coding tables, evidence justifications and answers for seven research questions.
## Contents

| File | Coverage |
| --- | --- |
| `RQ1_Supplementary_Material.pdf` | Reinforcement-learning method-family characterization and recommendations |
| `RQ2_Supplementary_Material.pdf` | Reinforcement-learning formulation consistency and cross-study comparability |
| `RQ3_Supplementary_Material.pdf` | Application scope, subsystem coverage, and under-reviewed areas |
| `RQ4_Supplementary_Material.pdf` | Occupant framing, human-centric metrics, and metric imbalances |
| `RQ5_Supplementary_Material.pdf` | Validation maturity, deployment readiness, and simulation-to-real gaps |
| `RQ6_Supplementary_Material.pdf` | Reproducibility, benchmarking, and research infrastructure |
| `RQ7_Supplementary_Material.pdf` | Challenges, future directions, and evolving priorities |

Each PDF includes:

- Survey-level evidence and audit tables
- Research-question-specific synthesis
